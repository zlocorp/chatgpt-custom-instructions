# v5: Custom Instructions for GPT-6-era ChatGPT

Two general-purpose Custom Instructions variants:

- **Compact** (1,394 / 1,500 characters): Free and Go.
- **Extended** (4,949 / 5,000 characters): plans with the larger field.

Changes include task-adaptive self-review, proportionate verification, completion of authorized work, preservation of editing requirements, and optional rich presentation where supported. Neither variant installs tools or enables unavailable features.

These are evidence-informed prompts, not benchmark-proven improvements. Earlier versions and original attribution are preserved.

Download the TXT assets from the release when published, or copy the fenced prompt from the Markdown files. Use only one variant.
